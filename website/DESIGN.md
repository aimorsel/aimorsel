# 官网设计说明

给改这个站的人看。样式全部在 `assets/site.css` 一个文件里，没有构建步骤。

## 方向

**「查询台」**：首屏不讲转换，讲检索——先要大纲，再取那一节，命中带页码。
页面用的是界面语言（查询条、结果行、命中高亮），页面本身就是产品的演示。
两处外来元素：整幅深色带只讲「离线」这一件事；标注文档图沿用产品自己的输出配色。

## 颜色纪律（越界即错）

每个语义色只有一份工作。破坏这条，颜色就不再传递信息，只剩装饰。

| Token | 值（浅 / 暗） | 唯一用途 |
|---|---|---|
| `--accent` | `#1F5FD0` / `#6E9BFF` | 品牌色，也是页面上**唯一的可交互色**：链接、按钮、焦点、当前项 |
| `--ok` | `#17795C` / `#46AE8D` | 文档语义：正文块、表格、成功、命中缓存 |
| `--hit` | `#FFD65A` / `#F2C63C` | **只**标检索命中，绝不当强调或装饰 |
| `--warn` | `#C2600F` / `#E08A3C` | **只**标需复核、已知限制、未填的占位 |

蓝和绿不是挑出来的：它们就是质量自检（`--qa`）生成标注版 PDF 时给标题框和正文框用的颜色。
所以官网上任何一张真实截图都自带品牌识别——**换掉这两个色，这个论点就没了**。

中性色是冷偏蓝的灰，与标注蓝同源，不用纯灰。

## 深色带

`.band` 是全站唯一的整幅深色区，**只用于「离线」这一个主张**，复用到别处它就不再等于离线。
暗色主题下它反过来做成「抬起的台面」（比页面底更亮），靠明度差区分——
沿用浅色主题的近黑值会让它在暗色页面上彻底消失。

## 字体

- **Instrument Sans**（可变 400–700）拉丁显示与正文；**IBM Plex Mono**（400/500）页码徽标、
  溯源标签、代码。均为 OFL 许可，许可全文在 `assets/fonts/`。
- 自托管 Google 已按 `unicode-range` 切好的 latin / latin-ext 子集，**5 个文件共 80KB**。
  不挂任何字体 CDN——一个宣称「文件不出本机」的工具，官网自己就不该往外发请求。
- 中文没有可行的自托管方案，走系统栈（PingFang SC / Noto Sans SC / 微软雅黑），
  由 `unicode-range` 自动分流。
- 行高按语种分开：中文 `1.78`、拉丁 `1.62`，由 `<html lang>` 触发。

## 组件

`assets/site.css` 里按注释分区。核心的几个：

- `.pg` 溯源徽标——全站原子组件，只承载「这东西来自哪里」，不放状态或分类
- `.row` / `.row--on` 结果行——功能列表、文档目录、检索结果共用；`--on` 一组里最多一条
- `.desk` 查询台面板——首屏签名元素，**全站只出现一次**，也是唯一用到 `--sh-2` 阴影的地方
- `.page` / `.blk` / `.tag` 标注文档图
- `.tablewrap--narrow` 表格放进两栏版面时的变体（不加会撑破容器）
- `.docs` 文档页三栏模板
- `.chart` / `.cgroup` / `.bars` 评测条形图（首页 `#bench`）——一张图三组指标，纯 HTML + 内联 SVG，条宽是 SVG `width` 属性不是 `style`；
  **颜色 = 引擎**，用独立的分类色 token `--c-us/--c-docling/--c-pymupdf/--c-markitdown/--c-pdfplumber`（浅/暗各一套），
  只在这张图和它的图例里出现，不占用也不混用四个语义色

阴影只有两级，其余一律 1px 描边。圆角三档，`--r-pill` 只给页码徽标。

## 硬约束

改动时不要破坏这些：

1. **零外部依赖**：不引框架、不挂字体 CDN、不上统计脚本、不外链图片。全站断网可完整渲染。
2. **零构建**：手写 HTML + 一份 CSS，本地双击就能看，直接丢 Cloudflare Pages。
   页面之间用相对路径 + 显式 `index.html`，这样本地和线上都通。
3. **中英各自成页**，`hreflang` 互指。两边是手写的，**改一边记得改另一边**。
4. **占位不填假值**：下载直链、首次运行提示的措辞、正式版本号——发布前才填。
5. **无出处的数据不上站**。首页 `#bench` 一节的竞品对比已按 `bench/RESULTS.md` 填好
   （2026-08-19，731 份 × 5 引擎），**每一行都能点到出处**——表下的链接指向仓库里的完整结果表。
   规矩不变：重跑评测后数字变了，首页与 README 要一起改；新增的数字同样必须有出处。
6. 无障碍：可见焦点框、跳到正文链接、尊重 `prefers-reduced-motion`、深色带上文字对比度同样达标。
